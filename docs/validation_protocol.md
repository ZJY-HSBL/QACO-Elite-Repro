# 多地图独立验证与消融协议 / Independent paired validation

## 目的与证据等级

本文（刘炀、吴艺茹、张恒，2026，DOI: 10.13462/j.cnki.mmtamt.2026.09.024）给出了 20×20 栅格、0.2/0.3/0.4 障碍物密度下的三组结果。其原始地图、随机种子、部分重要实现条件和代码未公开。因此：

1. `qaco_elite.experiment`：**论文参数层面的单地图基准**，使用原文 50 只蚂蚁、100 次蚁群迭代；但地图不同，不应做数值重合声明。
2. `qaco_elite.validation`：**新增的外部独立验证**。同一张地图上对照五种方法，以不同随机地图种子配对评估。它并非原论文报告的实验。
3. 若要原文逐点一致，仍需作者发布原始三张 20×20 栅格地图/随机数状态、完整 Q 训练预算、Q 值正值处理与蚂蚁路径死锁策略。

## 源码与参数的一致性

- 八邻域移动，必须经过两个相邻空格才允许对角移动；普通移动代价为 1，对角为 √2。
- Q 学习：正常移动 −1，碰撞/越界 −10，到达终点 +10；Boltzmann 温度 `max(0.01, 5 * exp(-0.01 * episode))`；`alpha1=0.2, gamma=0.9, lambda=0.5`。
- 蚁群：`alpha=1, beta=5, nu=2, m=50, E=5, rho=0.2`，相应原文式 (3)–(17)。
- 论文未给出的超参，保留明确默认值：Q 训练回合数、截断步数、初始信息素、回退规则和逐状态 Q 值正值映射。
- `Elite-NoHeuristic` 将 Q 学习的 λ 设为 0，其他固定。`Elite-NoQ` 以单位先验代替 Q 信息，**但仍使用精英强化**，用于隔离 Q 值引导贡献。
- `Dijkstra` 只作为相同栅格下的精确几何最短路径参考，不参与三种论文算法的学习或优化。

## 控制变量与统计报告

- 每档障碍物密度抽取 `N` 张 *连通* 地图。由于按连通性拒绝采样，实际障碍物比例可能不等于标称的伯努利抽样概率（分组依据为抽样概率）。
- 同一地图内所有算法共用地图、ACO 随机种子；Q-ACO 和 Q-ACO-Elite 共享同一张预训练 Q 表。消融 Q 表重训时也使用对应 Q 随机种子。
- 主指标：`best_length`。附带路径长度对 Dijkstra 的差距百分比、转角代价、最终最佳路径第一次出现的迭代、成功蚂蚁比例、Q 离线学习时间、ACO 在线时间及二者合计时间。
- 对四个比较分别求同地图配对差（`前者 − 后者`，正值表示后者更短），进行 10,000 次配对 bootstrap，报告均值的探索性 95% 百分位区间；双侧随机符号翻转检验给出 `p_raw`，每个密度的四个**路径长度**比较采用 Holm 校正。转角与迭代指标是探索性次要比较，未做多重校正。
- 每个地图和算法保存实际种子、地图哈希、障碍比例、原始指标和逐轮历史。避免把单次实验误写成统计显著性。

## 命令

```bash
python -m pip install -e '.[test]'
python -m pytest -q
# 第一层：50 蚂蚁 × 100 次迭代的论文框架单地图示例
python -m qaco_elite.experiment --output results --seed 2026 --q-episodes 1200 --ants 50 --iterations 100 --walk-cap 1800
# 第二层：多地图评估，参数可按计算预算调整，不得与上面的单地图实验混称
python -m qaco_elite.validation --output results/validation --seeds 6 --q-episodes 450 --ants 20 --iterations 40 --walk-cap 750 --resamples 10000
```

`results/validation/` 中包含 `individual_runs.csv`（所有真实实验明细）、`summary.csv`（各指标均值与离散度）、`paired_effects.csv`（配对差和置信区间）、`manifest.json`（参数与原论文参照值）、`trajectories.json`、`q_training.json`、每组路径图、平均收敛图与配对效果图。

## 注意

本数据是**真实 Python 模拟**，不是仓储车实体系统实测。未评估动力学、转角半径、非完整约束、冲突调度、多 AGV 干扰、实时重规划、能耗或者机器人实物安全性。论文仅讨论静态栅格上的路径规划，不能由图中转角代价直接推断实体 AGV 的真实能耗或吞吐量。
